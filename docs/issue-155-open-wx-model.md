# Source-declared `fs.open` with literal `wx` mode

`SourceDeclaredFsOpenWxCall` identifies a direct, non-optional source-declared `fs.open` call with two or three raw non-spread expression arguments and a String mode at index 1 containing exactly one `StringFragment` with value `wx`. It exposes the raw path at index 0, mode at index 1 and optional permission expression at index 2. Omitted permission is accepted; omitted mode, extra arguments, spread, other or dynamic modes, and nonmatches are inconclusive. The optional permission expression is not validated as a runtime integer. Conservative whole-file competing-name exclusions do not prove lexical or runtime callee binding. The model adds no flow, handle, Concepts sink, sanitizer, authorization, `path_found` or security result, and does not change the default security suite.

The real fixture is the existing [WeeChat source and attribution](../ql/test/luci-fixture-attribution/README.md), LuCI commit `b2e0be4b46ec0fd43394c081fa7c50657af14011`, Git blob `9f17ae3718a278eab2813ccfae4f2c732a9118e8`, SHA-256 `548213868a38bd84d8a9cb9b9842c647d4e79fa9df21b815b6b869f26a54e44e`. Line 365 contains `open(tmp_file, 'wx', 0640)`; staging source bytes does not prove installed image contents. Native ucode source at `b885dd0fe1e974551fb1233ca5f3aa74d80b74d9`, `lib/fs.c` blob `46c71d34ac95c7b6f318cce4cf696b4a3d04f115`, reads path, mode and permission from argument slots 0, 1 and 2. That source does not prove this call's imported binding, an actual syscall, a successful open or a later write.

The [source-first manifest](../ql/test/issue155-open-wx/manifest.json) records the real site and synthetic controls before extraction. `scripts/m4-open-wx-model-smoke.sh` stages those sources, checks routing, source archive and diagnostics, independently witnesses raw AST and typed argument/import/string-fragment edges, and compares exact path/mode/membership rows and the separate optional-permission relation. Counterfactuals test wrong path and mode slots, single-fragment versus extra escape, mode value, argument shape and individual source-attribution guards. Duplicate imports and reassignments are source-syntax controls; compiler or runtime acceptance is unknown. The malformed error position was specified before extraction. The prior audited rename extraction witnessed this real open call but did not run this model.

A local macOS run against a frozen working-tree snapshot based on `8949bfab8d1e057dc0c06659da266b9d18cec0cb` reported that the gate passed, including 28 successful routes, one expected malformed diagnostic, four model members and the counterfactual controls. An independent raw-output audit passed for all 45 commands, 29 routes, model and permission rows, counterfactuals, and the malformed diagnostic. The extractor pack was built from `104a398468f214961168d2edc9a10be45b80062f`; the selected tracked extractor, build and schema inputs were unchanged at the snapshot base. This is not a claim of a pack built at that base, committed-head verification or hosted CI.
