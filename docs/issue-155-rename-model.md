# Source-declared two-argument `fs.rename` model

`SourceDeclaredFsRenameCall` identifies a direct, non-optional call attributed by source syntax to an earlier unaliased named `rename` import from `fs`, with exactly two raw expression arguments. It rejects spread arguments and other arities. `getSourceArgument()` exposes argument 0 and `getDestinationArgument()` exposes argument 1. The shared attribution predicate excludes same-name competing bindings and writes across the file. These conservative exclusions do not prove lexical or runtime callee binding; unsupported forms and nonmatches are inconclusive. This model adds no flow edge, Concepts sink, runtime target, sanitizer, `path_found`, authorization or security finding, and does not change the default security suite.

[LuCI fixture license and attribution](../ql/test/luci-fixture-attribution/README.md) accompany the copied source.

The real source fixture is LuCI commit `b2e0be4b46ec0fd43394c081fa7c50657af14011`, `applications/luci-app-weechat/root/usr/share/rpcd/ucode/weechat.uc`, Git blob `9f17ae3718a278eab2813ccfae4f2c732a9118e8`, SHA-256 `548213868a38bd84d8a9cb9b9842c647d4e79fa9df21b815b6b869f26a54e44e`. The line 374 call `rename(tmp_file, path)` has destination `path` at argument index 1. The source path copied into the test staging root is not evidence of an installed image. Pinned ucode native source commit `b885dd0fe1e974551fb1233ca5f3aa74d80b74d9`, `lib/fs.c` blob `46c71d34ac95c7b6f318cce4cf696b4a3d04f115`, assigns old and new paths to indexes 0 and 1; that source description does not establish the runtime identity of this imported callee or that any rename succeeds.

The [source-first fixture manifest](../ql/test/issue155-rename/manifest.json) pins byte spans, node kinds and expected model membership before extraction. The aggregate QL smoke `scripts/m4-rename-model-smoke.sh` stages the real fixture and isolated positive and negative controls. It verifies byte hashes, routing, archived bytes, file success and extraction-error identities, raw AST identities and typed call, import and argument edges, exact source and destination nodes and membership multiplicity. A separate testing query deliberately returns the source node as destination; the gate requires that counterfactual to fail the same exact-identity oracle. Single-guard counterfactual queries are generated from the shared source-attribution predicate for declaration, assignment, module, alias, optional-call, duplicate-import and diagnostics guards, with exact added-row expectations. The argument-shape counterfactuals are separate raw-predicate counterparts, not mutations of `Models.qll`. Duplicate-import and assignment controls are source-syntax tests only; compiler acceptance and runtime behavior are not established. The malformed diagnostic position was specified before extraction from the matching stat-control parser observation.

An independently audited local macOS run used a frozen working-tree snapshot based on `4f5b2ab` and an extractor pack built from `104a398`, whose relevant extractor inputs were verified source-equivalent for this run. It observed 20 routed files, 19 successful-file rows, one expected malformed-file error, three exact model rows and three membership rows. The wrong-index, argument-shape and seven guard counterfactuals matched their source-first expectations. The run retained query-loading cache-size, unattached QLDoc and unused-predicate warnings. This is working-snapshot evidence, not a result for the later integration head, Linux or hosted CI.
