# Source-declared UCI commit association controls

This is a bounded source association for a direct literal-argument `.commit`
call on a local directly initialized with a source-declared `cursor()` import.
It is not resolution of the installed UCI module, a proven effect or successful
commit, dataflow, a security sink, a `path_found`, or an authorization finding.
A missing association is inconclusive. Constructor aliases, receiver aliases,
optional calls, computed calls, dynamic or omitted config arguments, ambiguous
bindings, unsupported writes, and malformed files are outside the subset;
zero-argument `commit()` is a documented native form and is not declared invalid.
Receiver and direct member/subscript writes, including parenthesized write
operands, are conservatively guarded where recognized; this does not establish
that a receiver or method stays unchanged after an escape or via other forms.

The retained LuCI source attribution and license are in [ATTRIBUTION.md](ATTRIBUTION.md).
The source-first manifest records exact input bytes and expected positive AST
anchors before extraction. Test-only adjacency joins a qualifying association
to an immediately following fixed `system` restart in a shared statement owner;
it records source adjacency only and does not implement or satisfy #156. A
negative, missing or unresolved candidate must not be interpreted as safe.
The CLI runner checks exact routes, source archive, diagnostics and projected
entities; generated guard mutants test specific false-positive conditions.
